Dogs vs. Cats Classification Using CNN

Project Description

This project uses a Convolutional Neural Network (CNN) to classify images as either cats or dogs using deep learning.

Objectives

- Build an image classification model using Python.
- Train a CNN using TensorFlow and Keras.
- Evaluate model performance using accuracy and a confusion matrix.

Technologies Used

- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Scikit-learn

Dataset

Cats and Dogs filtered dataset, containing separate training and validation images.

Methodology

1. Download and prepare the dataset.
2. Resize images to 160 × 160 pixels.
3. Build and compile the CNN model.
4. Train the model for 5 epochs.
5. Evaluate validation accuracy.
6. Generate an accuracy graph and confusion matrix.
7. Save the trained model in Keras format.

Project Files

- "Dogs_vs_Cats_Classification.ipynb" — Python notebook and code.
- "accuracy_curve.png" — Training and validation accuracy graph.
- "confusion_matrix.png" — Model evaluation results.
- "dogs_vs_cats_model.keras" — Saved trained model (to be uploaded if not already present).

How to Run

1. Open the notebook in Google Colab.
2. Run the code cells in order.
3. Allow the dataset to download and the model to train.
4. Review the accuracy graph and confusion matrix.

Conclusion

This project demonstrates a basic deep learning workflow for distinguishing cat images from dog images using CNN.
